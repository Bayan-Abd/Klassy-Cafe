# Klassy Cafe
موقع ويب متكامل و مستجيب لمقهى تم تصميمه باستخدام لغات الويب الاساسية ليتناسب مع جميع الشاشات (Responsive) 
# التقنيات المستخدمة 
**HTML5:** لبناء الهيكل الاساسي للموقع و توزيع العناصر 
**CSS3:** لتنسيق الالوان  الخطوط و الخلفيات و اضافة تاثيرات الظلال و الحركة
**media Queries:** لضمان استجابة و تناسق الموقع على الهواتف و الأجهزة اللوحية 
## المميزات 
- نصميم عصري و جذاب و مناسب للهوية البصرية للمقاهي
- قسم خاص لعرض الأطباق المميزة و الصور بشكل مرن
- تموذج form مخصص لحجز الطاولات و التواصل 
- متوافق تماما مع الشاشات الصغيرة (Responsive Design)
